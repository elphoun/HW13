# HW13 / Slackoff

| Folder | What it is |
| --- | --- |
| `slackoff-airpod/` | macOS Swift streamer that reads AirPod motion and sends it to the web app. Also has the downloadable `dist/AirPodStreamer.zip` for friends. |
| `slackoff-web/` | The game (Three.js) and Node server that relays AirPod input and player state. |
| `slackoff-bot/` | The Slackoff bot. |

See each folder's README for how to run it.
